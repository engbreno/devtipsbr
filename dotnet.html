📦 Como Criar e Usar Pacotes NuGet Locais

🧱 Parte 1 — Projeto que será o pacote

1. Configure o .csproj para gerar pacote automaticamente
<GeneratePackageOnBuild>true</GeneratePackageOnBuild>
<Version>1.0.0</Version>
<PackageId>Projeto.Core</PackageId>
2. Gere o pacote NuGet (.nupkg)
dotnet build -c Release
3. Crie a pasta local onde seus pacotes ficarão salvos
mkdir C:\Dev\LocalNugets
4. Copie o pacote gerado para a pasta local
copy .\bin\Release\Projeto.Core.1.0.0.nupkg C:\Dev\LocalNugets
5. Adicione a pasta como uma fonte NuGet
dotnet nuget add source "C:\Dev\LocalNugets" --name LocalNugets

🔧 Parte 2 — Projeto que vai usar o pacote

1. Referencie o pacote no .csproj
<PackageReference Include="Projeto.Core" Version="1.0.0" />
2. Restaure os pacotes
dotnet restore

🔁 Atualizações futuras

1. Atualize a versão no projeto pacote
<Version>1.0.1</Version>
2. Compile e copie novamente para a pasta
dotnet build -c Release
copy .\bin\Release\Projeto.Core.1.0.1.nupkg C:\Dev\LocalNugets
3. Atualize o .csproj consumidor para nova versão
<PackageReference Include="Projeto.Core" Version="1.0.1" />
Definir versão no .csproj
<Version>1.0.0</Version>
Gerar pacote NuGet automaticamente
dotnet build -c Release
Adicionar pasta como fonte NuGet

Copiar pacote gerado para a pasta
copy .\bin\Release\Projeto.Core.1.0.0.nupkg C:\Dev\LocalNugets\
Referenciar pacote no .csproj

Atualizar versão no .csproj quando houver mudanças
<Version>1.0.1</Version>

Entity Framework Core 🗃️

Instalação das Ferramentas

Instalar a ferramenta EF Core globalmente
dotnet tool install --global dotnet-ef
Atualizar a ferramenta EF Core
dotnet tool update --global dotnet-ef
Verificar versão da ferramenta
dotnet ef --version

Migrações

Adicionar migração
dotnet ef migrations add NomeDaMigracao
Remover última migração
dotnet ef migrations remove
Listar migrações
dotnet ef migrations list
Gerar script SQL
dotnet ef migrations script
Gerar script SQL de uma migração específica para outra
dotnet ef migrations script MigracaoInicial MigracaoFinal

Banco de Dados

Aplicar migrações ao banco de dados
dotnet ef database update
Aplicar uma migração específica
dotnet ef database update NomeDaMigracao
Remover todas as migrações (drop database)
dotnet ef database drop
Criar a partir do modelo atual (sem histórico)
dotnet ef database update 0

Engenharia Reversa

Gerar modelos a partir de banco existente
dotnet ef dbcontext scaffold \
"Server=.;Database=Northwind;Trusted_Connection=True;" \
Microsoft.EntityFrameworkCore.SqlServer
Gerar modelos para tabelas específicas
dotnet ef dbcontext scaffold \
"ConnString" Microsoft.EntityFrameworkCore.SqlServer \
--table Customers --table Orders

Build e Publicação 🚀

Compilação

Compilar projeto
dotnet build
Compilar com configuração específica
dotnet build --configuration Release
Compilar para versão específica do framework
dotnet build --framework net6.0
Compilar com detalhamento
dotnet build --verbosity detailed

Publicação

Publicar aplicação
dotnet publish
Publicar com configuração Release
dotnet publish --configuration Release
Publicar para pasta específica
dotnet publish --output ./publish
Publicar como autocontido (sem necessidade de runtime instalado)
dotnet publish --self-contained \
--runtime win-x64
Publicar como executável único (trimado)
dotnet publish -r win-x64 \
-p:PublishSingleFile=true \
-p:PublishTrimmed=true \
--self-contained

Empacotamento

Empacotar projeto como NuGet
dotnet pack
Empacotar com configuração Release
dotnet pack --configuration Release
Empacotar com versão específica
dotnet pack -p:PackageVersion=1.0.0

Soluções 🗂️

Criação e Gerenciamento

Criar nova solução
dotnet new sln -o MinhaSolucao
Adicionar projeto à solução
dotnet sln MinhaSolucao.sln add MeuProjeto/MeuProjeto.csproj
Adicionar múltiplos projetos
dotnet sln MinhaSolucao.sln add **/*.csproj
Remover projeto da solução
dotnet sln MinhaSolucao.sln remove MeuProjeto/MeuProjeto.csproj
Listar projetos na solução
dotnet sln MinhaSolucao.sln list

Referências entre Projetos

Adicionar referência a outro projeto
dotnet add MeuProjeto/MeuProjeto.csproj \
reference Biblioteca/Biblioteca.csproj
Remover referência a outro projeto
dotnet remove MeuProjeto/MeuProjeto.csproj \
reference Biblioteca/Biblioteca.csproj
Listar referências de um projeto
dotnet list MeuProjeto/MeuProjeto.csproj reference
